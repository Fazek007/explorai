# Explorai

Explorai is a local chat application for trying a language model on your own machine. The page is TypeScript. The API is Django, and conversations are stored in SQLite. Replies come from a local model through Ollama, with retrieval over a small set of notes.

This is an experimental learning project, and it is still in the works. The code is there to be read, and you are very welcome to look through it.

How a message is handled is described in [ARCHITECTURE.md](ARCHITECTURE.md).
